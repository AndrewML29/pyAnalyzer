# StreamStats - Потоковый анализатор логов

Инструмент командной строки для обработки больших файлов логов в форматах JSONL и CSV.
Программа работает потоково, что позволяет обрабатывать файлы любого размера с минимальным потреблением оперативной памяти.

## Возможности
- Чтение файлов JSONL и CSV.
- Валидация обязательных полей (timestamp, level, source, message).
- Подсчет общего количества событий и распределения по уровням логов.
- Отслеживание временных меток (первое и последнее событие).
- Выявление топ-5 источников ошибок (уровни ERROR и CRITICAL).
- Генерация итогового отчета в формате JSON.

## Установка
Убедитесь, что у вас установлен Python 3.8+ и пакет `poetry` (или просто используйте стандартную установку зависимостей).

## Использование
```bash
python -m streamstats analyze <путь_к_файлу> --format <csv|jsonl>
